### ✅ LEGAL & ETHICAL:
1. **Public Domain Scanning**
   - Expired domains (GoDaddy, NameCheap)
   - USPTO public trademark database
   - Public GitHub repos (with API limits)
   - Google Trends public data

2. **Fair Competition**
   - Using published APIs within rate limits
   - Respecting robots.txt
   - Following registrar terms of service

3. **Transparent Pricing**
   - Fair market value based on data
   - No domain squatting on active trademarks
   - No typosquatting

   - Tracking founder wallets without consent

   - Exceeding rate limits

   - Front-running based on leaked info
